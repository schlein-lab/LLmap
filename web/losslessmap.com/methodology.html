Methodology

Bench harness

We run a 4-mapper cross-species shootout on synthetic reads generated by benchmarks/scripts/gen_synth_reads.py with controlled error profiles and ground-truth alignment positions. Mappers under test:

  • LLmap — wave-particle adaptive λ, GPU + AI optional.
  • minimap2 — baseline long-read mapper (seed-chain-extend).
  • bwa-mem2 — short-read baseline (mostly skipped on long-read tiers).
  • winnowmap — repeat-aware long-read mapper (run where applicable).

Tier ladder (gen_synth_reads.py tiers 1–10)

Each tier intensifies a stress dimension. Tiers 1, 2, 5, 6, 10 are the standard scoreboard checkpoints. T1/T2 are the human-genome deep-dive cuts.

  • tier1 — clean HiFi-like reads, low error, unique regions emphasized.
  • tier2 — mixed error profile, balanced region coverage.
  • tier5 — elevated indel rate, repetitive flanks.
  • tier6 — structural variants (DEL/DUP/INV) layered on tier5 reads.
  • tier10 — worst case: SVs + high error + telomere/centromere mass.
  • T1 / T2 — human-genome-specific tiers (whole-genome, real chromosome lengths).

Region classes

Each truth read is annotated with the region class of its origin coordinate, so downstream metrics can be sliced by hardness band:

  • unique — single-copy reference regions.
  • SD — segmental duplications.
  • centromere — high-order repeats, alpha satellite.
  • telomere — terminal repeat blocks.
  • low_complexity — short-period tandem repeats.
  • SV_DEL / SV_DUP / SV_INV — reads spanning synthetic structural variants (tier6+).
  • all — aggregate across the whole truth set for that tier.

Metrics

For every (mapper, region_class) pair we record:

  • F1@100bp — harmonic mean of precision/recall where a read is "correct" if its predicted alignment is within 100 bp of the truth coordinate (strand-aware). This is the strict F1 used for color-coding on the scoreboard.
  • F1@1kb — relaxed tolerance, useful for SV reads where the truth coordinate is only well-defined up to breakpoint resolution.
  • mapping rate, mean MAPQ, peak RSS, wallclock.

Color buckets

✓ F1 ≥ 0.99 ✓ F1 ≥ 0.90 ⚠ F1 ≥ 0.70 ✗ F1 < 0.70 — NA (mapper skipped)

Reproducing the bench

From the repo root:

cd benchmarks
bash run_local_synthetic.sh         # local quick smoke
python3 orchestrate.py              # full local matrix
sbatch the HPC cluster_submit_t3_t6.sh       # SLURM heavy tiers (the HPC cluster)
python3 report.py                   # rebuild scoreboard.tsv + summary.md
python3 ../web/losslessmap.com/build.py   # rebuild this site

Self-hosting / deployment

To self-host the scoreboard:

cd web/losslessmap.com && python3 -m http.server 8080

For losslessmap.com deployment, either

  • rsync -av web/losslessmap.com/ user@losslessmap.com:/var/www/losslessmap.com/, or
  • push web/losslessmap.com/ to a gh-pages branch and point the domain's CNAME at the GitHub Pages site.

  • benchmarks/scoreboard_pivoted.tsv — pivoted view (organism × tier × region_class → mapper F1).
  • benchmarks/reports/<organism>/<tier>/summary.json — per-cell deep-dive.
